Lint rule index

Built-in lint rules ship with TypeRB and use the trb release version. Every rule has one stable ID and one documentation page.

Rule Default Recommended Fix Since
trb/prefer-conditional-transfer warning yes safe cases 0.3.25

Configure rule levels under lint.rules in trbconfig.jsonc. See the linting guide for presets, command status, fixes, and versioning policy.
