Getting started

TypeRB is a statically typed programming language. The v0.5 alpha series introduces the Native compiler as the default trb and retains the Go implementation as trbg.

Install

On Arm64 macOS or Linux:

brew install type-rb/tap/trb
trb --version

If you already installed trb with Homebrew, run brew upgrade type-rb/tap/trb. Native executable builds use the system C toolchain. See the Native command guide for the available commands and modes in this alpha.

The Go compiler provides the Go, Ruby, and TypeScript workflows used in the rest of this guide. Install it on Arm64 or x86-64 macOS or Linux, then use trbg wherever the examples invoke the Go compiler:

brew install type-rb/tap/trbg
trbg --version

Both commands can be installed together. See the alpha release for platform archives and known feature gaps.

Run a standalone program

Create hello.trb:

def main()
	name := "TypeRB"
	puts("Hello, " + name + "!")
end

TypeRB needs only the toolchain for the target you choose. The Go examples in this guide use Go 1.27.4. The Ruby target runs on Ruby 4.0.10. TypeScript output is checked with TypeScript 7.0.2 and runs on Node.js 26.13.1 or Bun 1.4.5. Install the tools for the target you plan to run.

Run the program in Go mode to follow the rest of this guide:

trbg hello.trb

If you prefer another target, run only the corresponding command:

trbg run --mode ruby hello.trb
trbg run --mode typescript --runtime bun hello.trb

Start the typed REPL from any directory with trbg. It uses Go mode when no project configuration is present:

$ trbg
trb:go> 1 + 2
3 : Integer

Create a project

Create a Go project:

trbg init --mode go --module example.com/hello hello
cd hello

Create main.trb:

def main()
	puts("Hello from TypeRB")
end

Then format, lint, and run the project:

trbg fmt
trbg lint
trbg run

Use trb build to keep generated target source. Go projects can also produce an executable with trb build --compile.

Choose a target

  • Go is suitable for native binaries and services.
  • Ruby is suitable for server and application development.
  • TypeScript is suitable for browser and server applications.

A target mode selects the backend, toolchain, and package ecosystem. It does not change TypeRB grammar or portable semantics. Continue with the learning path, or use the language guide as a practical reference.
